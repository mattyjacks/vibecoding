# DVA Remotely Solutions — proposal demo

Open `index.html` directly, or serve this directory with `python -m http.server 8091`.
No build, dependencies, external fonts, icon CDNs, or remote image services are needed.

This under-construction concept promotes MattyJacks.com. The information supplied by Bernadette is not a live availability feed. The contact form creates a WhatsApp deep link; visitors review and send the message themselves. There is no backend or stored inquiry data.

Structure: four HTML pages; modular CSS; progressive-enhancement JavaScript; original SVG favicon and eight SVG icons. All graphics are authored locally. Layouts adapt to mobile, keyboard navigation is supported, and reduced motion is respected.

Deploy the directory as static files. Configure your host to use `404.html` for missing pages if supported. All URLs are relative so the site also works at `/dva1/`.
